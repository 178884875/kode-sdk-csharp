# KodaClaw

KodaClaw 是一个基于 `Kode.Agent SDK` 的全新 `local-first` 个人 Agent 产品，目标是复刻并演进 PoorClaw 的完整产品形态：

- 有独立的本地 Gateway 与控制面
- 有可编辑的 Workspace 协议与长期记忆
- 有插件、渠道接入、自动化、Canvas
- 有独立的 Web 控制台与桌面壳
- SDK 只作为运行时内核，不直接把现有 example 改造成产品

## 产品原则

1. `local-first`：会话、工作区、插件、自动化优先驻留本地。
2. `inspectable autonomy`：允许 Agent 主动，但必须可见、可暂停、可审批。
3. `workspace as protocol`：人格、记忆、边界和长期任务通过文件协议表达。
4. `MCP-first plugin system`：优先用 MCP 统一插件与渠道，而不是先做进程内插件系统。
5. `desktop is shell, gateway is brain`：桌面端只做外壳，本地 Gateway 才是运行中枢。
